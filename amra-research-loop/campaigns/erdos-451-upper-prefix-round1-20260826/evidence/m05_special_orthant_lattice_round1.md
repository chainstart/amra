# U451-M05 round 1: the diagonal-plus-one CRT orthant lattice

Date: 2026-08-26

Status: **partial progress, not a closure of U451-M05 or Erdős 451**.  This
note proves an exact density-scale theorem for the *symmetric* offset box, a
`6^q` actual positive-orthant theorem for one dyadic width block, and an
`m^{Omega(m)}` obstruction for one precisely specified full-basis
sign-selection route.  The remaining obstruction is the multiscale common
orientation of the offsets.

Throughout, let `p_1,...,p_m` be distinct primes in `(k,2k)`, put

```text
d_i = p_i-k,       P = product_i p_i,       D = product_i d_i/p_i,
```

and consider

```text
Lambda = {(n,s_1,...,s_m) in Z^(m+1) : n+s_i = 0 (mod p_i) for every i}.
```

The actual 451 orthant asks for `n>2k` and `0 <= s_i < d_i` for every
`i`.  No assertion below replaces this one by a symmetric box without saying
so explicitly.

## 1. Exact determinant, rays, and Apéry ledger

The vectors

```text
v_0 = (1,-1,...,-1),       v_i = p_i e_i  (1 <= i <= m)
```

form a basis of `Lambda`: subtracting `n v_0` leaves the `i`-th offset
coordinate divisible by `p_i`.  Consequently

```text
det Lambda = P.                                             (1)
```

The primitive coordinate rays of `Lambda intersect R_{≥0}^{m+1}` are

```text
rho_0 = P e_0,       rho_i = p_i e_i.
```

Their ray sublattice has determinant `P^2`, hence index `P` in `Lambda`.
Its half-open ray parallelepiped

```text
Pi = [0,P) x product_i [0,p_i)
```

contains exactly the `P` points

```text
w(n) = (n, (-n mod p_i)_i),       0 <= n < P.               (2)
```

Exactly `product_i d_i` of them lie in the actual offset box.  Indeed each
offset independently has `d_i` permitted residues and CRT is bijective.
Thus the desired density is exactly `D`, but the primitive-ray Apéry set has
cardinality `P = exp((1+o(1))k)`.  This is a scoped warning: an argument which
enumerates the ray Apéry set or translates into the deep cone by `rho_0`
already pays the full exponential period.  It is not a no-go theorem for all
Hilbert-basis arguments.

There is also an exact failure of coordinate-ray sign repair.  If
`-(d_i-1) <= s_i <= -1`, then

```text
s_i+p_i >= p_i-d_i+1 = k+1 > d_i-1.                         (3)
```

So adding `rho_i` changes a negative symmetric representative into a point
beyond the positive target interval; adding `rho_0` costs `P` in `n`.

For comparison, the standard integer kernel formulation

```text
n+s_i-p_i a_i=0
```

has the support-minimal circuit

```text
(n,s,a) = (P,0,(P/p_i)_i).
```

It is primitive (the gcd of its nonzero entries is one) and no nonzero kernel
vector supported on a proper subset of these columns exists.  Hence the
Graver basis already contains an element of infinity norm `P`.  Any generic
Graver-complexity estimate depending on the largest Graver element therefore
pays `exp((1+o(1))k)` on this matrix.

### Covering-radius/flatness dual audit

For the quotient zonotope with half-generators `h(1/p_i)_i` and
`b_i e_i/p_i`, the support radius in a nonzero integral dual direction
`z in Z^m` is exactly

```text
R(z)=h |sum_i z_i/p_i| + sum_i b_i |z_i|/p_i.              (CR)
```

The zero-diagonal-frequency directions are unusually rigid.  If
`sum z_i/p_i=0`, multiplication by `P` and reduction modulo `p_i` gives
`p_i | z_i` for every `i`; writing `z_i=p_i t_i`, one has `sum t_i=0`.
Every nonzero such direction therefore pays at least the sum of the two
smallest `b_i` in the second term of (CR).

For a nonzero diagonal frequency, however,

```text
A=P sum_i z_i/p_i in Z\{0},
A = z_i(P/p_i) (mod p_i) for every i.                       (CR2)
```

The second term is bounded below by the weighted sum of the centered CRT
residues prescribed by `A`; enforcing the exact (rather than modulo `P`)
value of `A` can only add cost.  The first term alone only
gives `h/P`, which is useless when `h=exp(o(k))` and `P=exp((1+o(1))k)`.
Thus a covering-radius or flatness proof must either establish a new sharp
lower bound for these weighted CRT residues, or it has merely repackaged the
original phase problem.  Generic transference constants do not by themselves
exploit the diagonal-plus-one lattice.  This identifies the exact missing
dual input rather than claiming that every covering-radius route fails.

## 2. A density-scale symmetric successor theorem

This section is a positive result, but only for signed offsets.  Put

```text
b_i = d_i-1/2,       h = H+1/2,
D_b = product_i b_i/p_i,       S_b = sum_i 1/b_i.
```

### Lemma 2.1 (exact zonotope volume)

In `R^m`, let

```text
K_H = diag(1/p_i) {t 1 + u : |t|<h and |u_i|<b_i}.
```

Then

```text
vol(K_H) = 2^m D_b (1+h S_b).                               (4)
```

Proof.  This is the zonotope generated by the `m+1` segments with half
generators `h(1/p_i)_i` and `(b_i/p_i)e_i`.  The zonotope-volume formula is
`2^m` times the sum of the absolute `m` by `m` minors.  Omitting the diagonal
generator gives `D_b`; omitting coordinate generator `i` gives
`hD_b/b_i`.  Their sum is (4).  Endpoint openness does not change volume.

### Lemma 2.2 (integral reconstruction)

For a nonnegative integer `H`, every nonzero
`a in Z^m intersect K_H` produces integers `n,s_i` with

```text
0 < |n| <= H,       s_i=p_i a_i-n,       |s_i| <= d_i-1.    (5)
```

Proof.  Membership gives a common real `t` in all open intervals

```text
(-h,h),       (p_i a_i-b_i,p_i a_i+b_i).
```

All endpoints are half-integers.  A nonempty intersection of such intervals
has half-integral endpoints a positive integral distance apart, and therefore
contains an integer `n`.  The strict inequalities give (5).  If `n=0`, then
`|p_i a_i| <= d_i-1 < p_i`, so all `a_i=0`, contrary to the choice of `a`.

### Theorem 2.3 (symmetric successor beyond `2k`)

Let `H` be a nonnegative integer.  If

```text
D_b (1+(H+1/2)S_b) > 4k+1,                                (6)
```

then there are integers satisfying

```text
2k < n <= H,       n+s_i = 0 (mod p_i),
|s_i| <= d_i-1 for every i.                                (7)
```

Proof.  Apply quantitative Blichfeldt to `E=K_H/2`.  Since
`vol(E)=D_b(1+hS_b)>4k+1`, average the multiplicity
`sum_{z in Z^m} 1_E(x+z)` over `x in R^m/Z^m`.  Its average is `vol(E)`, so
for some `x` at least `4k+2` distinct points of the coset `x+Z^m` lie in
`E`.  Differences from one of them give at least `4k+1` distinct nonzero
integer points of
`E-E=K_H`.  Apply Lemma 2.2, choosing for each point `a` an integer in the
intersection used there.  For a fixed `n`, every `a_i` is unique because
`|p_i a_i-n| <= d_i-1 < p_i/2`; hence this map is injective.  There are only
`4k` nonzero integers with `|n|<=2k`.  Hence one has `|n|>2k`.
Simultaneous negation then gives (7).

The loss in replacing `D_b` by the actual density `D` is only polynomial:

```text
D/D_b = product_i d_i/(d_i-1/2)
       <= exp(sum_i 1/d_i) <= e k,                          (9)
S_b >= m/k.                                                 (10)
```

Here the `d_i` are distinct integers in `[1,k-1]`, and
`-log(1-1/(2d)) <= 1/d`.  Thus, for example,

```text
H = ceil(6 e k^3/(mD))                                     (11)
```

satisfies (6) for nonempty prime sets.  Under the prime number theorem for
the interval `(k,2k)`, this is

```text
H <= k^O(1) D^{-1},
log H = (log 4+o(1)) k/log k.                               (12)
```

Therefore the symmetric problem already has precisely the desired
`exp(o(k))` scale.  The unresolved content of M05 is not determinant or
density; it is orientation.

## 3. The exact orientation condition

For fixed quotient coordinates `a_i`, all representatives differ by a
common shift:

```text
(n,s_i) -> (n+t,s_i-t).                                    (13)
```

There is an integer shift placing every offset in the actual box iff

```text
max_i (s_i-d_i+1) <= min_i s_i.                            (14)
```

Equivalently, if `j` minimizes `s_i`, then

```text
s_i-s_j <= d_i-1 for every i.                              (15)
```

The additional lower bound is `n+t>2k`.  Thus the sign problem is a
one-dimensional common-shift compatibility condition, not `m` independent
coordinate sign choices.  Conversely, any actual target can be shifted by
`t=min_i s_i` so that one offset is zero, while increasing `n` by less than
`k`.  This reduces the search to a union of anchored faces, but does not
remove the CRT location modulo `P`.

There is an exact sign-pattern warning inside the actual lattice.  Assume
`d_i>=2`.  For every `sigma in {+1,-1}^m`, CRT supplies a unique
`0<=n_sigma<P` for the signed vector

```text
s_i=sigma_i(d_i-1),       n_sigma=-s_i (mod p_i).           (16)
```

If both signs occur, choose `j` minimizing `s_j` (so `j` is a negative
coordinate) and choose a positive coordinate `i`.  Then

```text
s_i-s_j=(d_i-1)+(d_j-1)>d_i-1,
```

so (15) fails.  Thus `2^m-2` exact symmetric CRT points in one period are
nonorientable.  This does not locate them below a short `H`, but it proves
that symmetric point count plus sign type alone cannot remove even a
constant-exponential sign tax; the additive structure and locations of the
Blichfeldt difference set must be used.

The constant-exponential tax can be counted over the entire signed Apéry
box.  It has exactly

```text
|S|=product_i(2d_i-1)
```

CRT points.  If `s in S` is orientable, write `s_i=q_i+t` with
`0<=q_i<d_i`.  Necessarily `|t|<2k`, so the number of orientable signed
vectors is at most `(4k+1)product_i d_i`.  Since the distinct `d_i` lie in
`[1,k-1]`,

```text
product_i d_i/(2d_i-1)
 = 2^{-m} product_i(1+1/(2d_i-1))
 <= e k 2^{-m}.                                            (SIGN)
```

Thus the orientable fraction of the full signed box is at most
`e k(4k+1)2^{-m}`.  This rigorously explains why a constant-exponential
orientation loss is natural and still affordable.  It does not imply that
the short Blichfeldt difference set is uniformly distributed in `S`, so it
does not turn the count into a positive theorem.

## 4. A `6^q` positive-orthant theorem for one dyadic width block

The common-shift condition does yield the desired loss when the widths have
one scale.  This is a theorem for a subsystem of primes, not yet a theorem
for all primes in `(k,2k)`.

Let `B` contain `q>=1` primes and suppose, for an integer `Delta>=1`,

```text
Delta <= d_i < 2 Delta       (i in B).                      (17)
```

Put

```text
w = floor((Delta-1)/2),       b=w+1/2,
delta_B = product_{i in B} d_i/p_i,
delta_b = product_{i in B} b/p_i,
H = ceil(4 k Delta/(q delta_b)).                            (18)
```

### Theorem 4.1 (single-block actual orthant successor)

There are integers satisfying all congruences for `i in B` and

```text
2k < n <= H+w,       0 <= s_i < d_i.                        (19)
```

Moreover

```text
H+w <= 6 (k^2/q) 6^q delta_B^{-1}.                         (20)
```

Proof.  Repeat the quantitative-Blichfeldt proof of Theorem 2.3 with all
signed half-widths equal to `b`, asking for `|n|>2k+w`.  Here

```text
sum 1/b = q/b >= 2q/Delta,
delta_b (H+1/2)(q/b) >= 8k.
```

Since `w<Delta/2<k/2`, this exceeds the `4k+2w+1` Blichfeldt threshold.
After simultaneous negation if necessary, obtain

```text
2k+w < n <= H,       |s_i|<=w.
```

Set `t=min_i s_i` and use the common lattice shift (13).  Then
`n'=n+t>2k`, while

```text
0 <= s_i-t <= 2w <= Delta-1 <= d_i-1.
```

This proves (19).  Finally `d_i/b<=6`: for even `Delta`, the worst case is
`Delta=2,d_i=3,b=1/2`; for odd `Delta` the ratio is below four.  Hence
`delta_b^{-1}<=6^q delta_B^{-1}`.  Using `Delta<k`, `q<=k`, and the harmless
ceiling and `w` terms gives (20): if
`A=(k^2/q)6^q delta_B^{-1}`, then `A>=6k`, while
`H+w<4A+1+k/2<6A`.

This realizes exactly the desired `C^q` loss inside one width scale.  It also
shows that the mixed-sign obstruction is not intrinsic to each block: it is
an interface obstruction between different scales.

If the full prime set were on one scale (`q=m`), its global ledger would be

```text
log(6^m D^{-1} k^O(1))
  = (log 6 + log 4 + o(1)) k/log k = o(k),
```

so Theorem 4.1 would close the required exponent in that special case.

### Why the dyadic blocks do not yet combine

There are only `O(log k)` blocks, but Theorem 4.1 supplies a different
integer `n` for each block.  Sequentially preserving completed blocks forces
the next search into a progression modulo the product of the completed
primes; after all blocks this modulus is `P=exp((1+o(1))k)`.  Adding the block
solutions is also invalid: a vector solving the congruences in one block has
uncontrolled residues in every other block.

For a simultaneous signed solution, each block separately supplies an
interval of common shifts, but the intervals need not intersect.  Shrinking
every coordinate to the smallest block width forces intersection, at the
cost

```text
product_i d_i/Delta_min,
```

which can again have logarithm `Theta(k)`.  Thus a legitimate merger needs a
new nested-shift or multiscale selection lemma; multiplying the `6^{q_j}`
local losses alone is not enough.  This is the precise block-interface gap.

Introducing one formal center `c_j` for each of the `L=O(log k)` blocks does
not by itself produce a low-dimensional lattice theorem.  Eliminating the
internal coordinates of block `j` leaves the periodic allowed set

```text
A_j subset Z/P_j Z,       |A_j|=product_{i in B_j}d_i,
P_j=product_{i in B_j}p_i.
```

The common `n` follows the diagonal orbit in `product_j Z/P_j Z`, whose
period is still `product_j P_j=P`.  If independently constructed local
solutions are aligned by replacing `n_j` by `n_j+t_jP_j`, CRT returns a
common value only modulo `P`; the first positive representative can again be
of order `P`.  Convexifying each `A_j` erases its phase, while applying
Blichfeldt to a translated block coset subtracts two points and cancels the
translation.  Therefore a generic `L^{O(L)}` theorem becomes useful only
after a new, phase-preserving compression of the `A_j` is proved.  Merely
introducing `L` center variables does not establish such a compression.

There is a second precise ledger for a vector-balancing implementation.
A pure `L`-dimensional loss `L^{O(L)}` would be affordable because

```text
log L^{O(L)} = O(log k log log k)=o(k).
```

But if the balancing theorem returns an integral combination of local
lattice vectors with coefficient `l1` norm `B`, their within-block errors add
by the same factor.  Keeping the final errors inside the boxes then requires
shrinking all `m` internal half-widths by `B`, whose density cost is `B^m`.
For the generic `B=L^{O(L)}` this has

```text
log B^m = O(m L log L)=O(k log log k),
```

which is much larger than `o(k)`.  A viable center reduction must therefore
pay `L^{O(L)}` only once in the projected phase space, or keep
`B=(log k)^{O(1)}` before it acts on the `m` internal coordinates.  Standard
Steinitz balancing applied to full vectors does not supply that separation.

## 5. A rigorous `m^{Omega(m)}` obstruction for the full-thin-basis route

This is the requested negative certificate for a *specified* standard route.
It is not a lower bound on every cone or semigroup method.

There is first an `exp(Theta(k))` obstruction to the elementary
cell-plus-monotone-subsequence route.  Partition residue coordinate `i` into
consecutive cells of length at most `d_i`.  Two times in one product cell
give the desired one-sided difference if their local residue vectors occur
in coordinatewise decreasing order.  However a full cell contains the
product poset

```text
product_i {0,...,d_i-1}.
```

Ranking by the coordinate sum partitions it into at most
`1+sum_i(d_i-1)<=mk` antichains, so a product cell `C` has an antichain of
size at least

```text
|C|/(mk).                                                   (CELL)
```

CRT realizes every vector in this antichain at a distinct time modulo `P`,
and no pair is comparable in either order.  Summing these antichain
capacities over all cells gives at least `P/(mk)`, because the cells partition
all `P` residue vectors.  Hence a proof that uses only cell occupancy and
generic product-order comparability has a worst-case threshold at least

```text
P/(mk)=exp((1+o(1))k).
```

This is an information-loss certificate, not a claim that those CRT times
form a long initial interval with no solution.  A successful order argument
must exploit their actual cyclic locations rather than only the poset width.

Let `r=m+1`.  Suppose one tries to find a full lattice basis
`W=(w_1,...,w_r)` and then solve for the center of the target orthotope and
round all `r` basis coefficients independently.  A sufficient thinness
condition is

```text
|w_{j,0}| < (H-2k)/r,
|w_{j,i}| < d_i/r       for every j and i.                  (21)
```

Indeed coordinatewise rounding makes the `n` error less than `(H-2k)/2`
and every offset error less than `d_i/2`, placing the resulting lattice point
strictly inside the target box.

But every independent `W` in `Lambda` has `|det W|>=P`.  Divide row zero by
`(H-2k)/r` and row `i` by `d_i/r`.  The normalized matrix has all entries of
absolute value below one, so Hadamard's inequality gives

```text
P <= |det W|
  < (H-2k) product_i d_i / r^(r/2).
```

Consequently this route necessarily requires

```text
H-2k > r^(r/2) / D.                                        (22)
```

For all primes in `(k,2k)`, `m=(1+o(1))k/log k` and
`log D^{-1}=(log 4+o(1))k/log k`.  Hence

```text
log(r^(r/2)/D) = (1/2+o(1))k.                              (23)
```

So full-rank thin-basis plus independent nearest-plane rounding has a genuine
`m^{Omega(m)}` barrier even for this diagonal-plus-one lattice.  If a matching
basis theorem existed it would suggest the weaker strict exponent
`exp((1/2+o(1))k)`, but it would still fail the M05 target `exp(o(k))`.
Generic `m^{O(m)}` Steinitz/flatness losses have the ledger

```text
log(m^(alpha m) (log k)^O(m) / D) = (alpha+o(1))k.          (24)
```

Thus `alpha=0` (for example `C^m` or `(log k)^O(m)`) is needed for closure;
`alpha=1/2` is only a strict exponent improvement, and `alpha>=1` gives no
leading improvement over the known full-period scale.

## 6. What is and is not established

Established exactly:

1. `det Lambda=P`, ray index `P`, and the `P`-point Apéry parametrization.
2. Coordinate-ray and generic Graver repairs incur the full period.
3. The symmetric signed-offset successor exists by
   `H <= 6e k^3/(mD)`.
4. Actual orientation is exactly the common-shift condition (14).
5. A single dyadic width block has an actual successor with loss `6^q`.
6. Cell occupancy plus generic product-order comparability has an
   `exp((1+o(1))k)` information-loss threshold.
7. The full-thin-basis/independent-rounding route must pay
   `r^(r/2)D^{-1}=exp((1/2+o(1))k)`.

Not established:

1. A multiscale merger of the single-block `6^q` theorems with total loss
   `C^m` or `(log k)^O(m)`.
2. A general `m^{Omega(m)}` lower bound for every Hilbert-basis, semigroup,
   discrepancy, or cone method.
3. An actual positive-orthant successor at `exp(o(k))`, hence no closure of
   U451-M05 and no solution of Erdős 451.

The strongest next target is now sharply isolated: starting from the many
density-scale symmetric points supplied by Blichfeldt, prove that one point
satisfies (14), at a loss at most `C^m` or `(log k)^O(m)`.  The full-box count
(SIGN) predicts a `2^m` tax but supplies no local equidistribution; precisely
that local orientation-distribution lemma is missing.  Any argument that
first constructs a full thin basis and rounds `m+1` coefficients separately
cannot meet that target by (22).
