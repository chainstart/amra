# Representation search

The search separates prime supply, padding geometry, incidence algebra,
query algorithms, and scope boundaries.

The decisive change is the dyadic prime reservoir.  A single interval
`(X,2X)` supplies all `Theta(K)` edge labels, so path length no longer
inflates the rough-part magnitude.  The padding calculation then has a
constant reserve `2A-2` and a constant maximum decrement five.

The incidence representation both proves minimality and exposes the
square-root boundary: every internal vertex contains two edge labels.

The query representations inherit the exact zero-transcript dichotomy.  The
stronger arithmetic cutoff is substituted without restricting off-zero
branches or introducing independence.  All-branch prime unions, vanishing
zero populations, global repairs, and per-input programs are retained only
as scope comparators.
