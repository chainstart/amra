# Independent audit: general formal unit matrix

## Verdict

The displayed all-`m` integer-matrix theorem passes blind reconstruction.
For every `m>=1`, the full formal matrix has rank `2m+2`, primitive gauge
kernel of rank one, and all nonzero Smith invariants equal to one.  The
source--identity subsystem has rank `2m+1`, primitive kernel generated by
the gauge and common-spectrum shift, and again has only unit nonzero Smith
invariants.

This is a formal incidence theorem only.  It is not the complete unit matrix
of every actual power-large block, and it changes neither the public
dimension-three `3/5` exponent nor any main exponent.  Promotion is rejected
and the campaign should freeze.

## Blind reconstruction

I did not import the author matrix builder or checker.  From variables

```text
(g,f,b,r_1,...,r_m,q_1,...,q_m)
```

I independently constructed coefficient rows

```text
S_i = g+r_i,
F   = f,
C_i = f+q_i,
B   = g+b,
I_i = b-r_i-q_i.
```

The affine right sides involving `s_i a` do not affect rank or Smith form.
They are consistent over the integers; for example choosing `g=a` gives the
integer particular solution displayed by the author.

### Full matrix

Use the `m` rows `S_i`, row `F`, the `m` rows `C_i`, and row `B`, and delete
the `g` column.  On columns

```text
(f,b,r_1,...,r_m,q_1,...,q_m)
```

successive elimination leaves unit pivots: `S_i` pivot on `r_i`, `F` on
`f`, `C_i-F` on `q_i`, and `B` on `b`.  This is a square
`(2m+2)`-minor of determinant `+/-1`.

Every row annihilates

```text
v_g=(1,0,-1,-1,...,-1,0,...,0).
```

There are `2m+3` columns, so the unit minor and this nonzero kernel vector
force rank exactly `2m+2` and rational nullity one.  Direct substitution
shows every integral kernel vector is an integer multiple of `v_g`; its
coordinates have gcd one, so the kernel line is primitive.  The unit maximal
minor makes the product of the nonzero Smith invariants one, hence every one
of them equals one.

### Source--identity subsystem

Keep `S_i`, `F`, and `I_i`, and delete columns `g,b`.  The remaining square
matrix on `(f,r_i,q_i)` has unit pivots `r_i`, `f`, and `q_i`, hence
determinant `+/-1` and rank `2m+1`.

It annihilates the independent primitive vectors

```text
v_g=(1,0,-1,-1_i,0_i),
v_s=(0,0, 1, 0_i,1_i).
```

Solving gives `r_i=-g`, `f=0`, and `q_i=b+g`.  Thus every integer solution
is exactly

```text
g*v_g + (b+g)*v_s,
```

so these vectors form an integral basis of the primitive kernel plane.  The
unit maximal minor again proves that every nonzero Smith factor is one.

Finally the formal identity rows really are redundant:

```text
I_i = B - S_i - C_i + F.
```

The same combination has zero affine right side, so this is not merely a
homogeneous coefficient coincidence.

## Formal `m` rows versus an actual power-large block

The archive does prove a power-large simultaneous normal form on a selected
leaf family:

```text
F_j=G R_j,  P_A0=G B,  B=R_j Q_j,  P_Aj=F0 Q_j.
```

Taking one already chosen valuation coordinate and fixing the absolute
products explains the formal row pattern.  It does not prove that this is
the complete actual matrix.  The gap has four separate parts:

1. The formal matrix records one scalar coordinate.  An actual Laurent unit
   group can have several exponent coordinates, coefficient units, signs or
   torsion, and the archive supplies no uniform tensor/coordinate theorem.
2. The complement rows `f+q_i=-s_i a` and `g+b=-2a` require absolute
   spectrum data.  No theorem fixes all such data across a power-large row
   family at only `t^o(1)` cost, nor converts their variation into distances.
3. The selected normal-form rows are not proved to list every factor
   occurrence, every relevant target row, and every cross-row relation.
   Extra equations may reduce a kernel; extra variables or absent absolute
   rows may enlarge it.  The formal calculation cannot choose between them.
4. Even a complete selected-chart matrix would not give the all-`qU` target
   occurrence mass `t^(28/9-o(1))`, maximum distance fibre below
   `t^(1/9-epsilon)`, or outer near-extremal stability required by `M10`.

This is the precise firewall between “all formal `m`” and “one actual
power-large block.”
