## 目标

每题先完成一次路线尸检，再尝试至少一种不同于最近两轮主路线的攻击。路线尸检
必须区分：

1. 证明链存在真实错误；
2. 证明正确但只给局部结果；
3. 路线在某个可证明屏障处失效；
4. 只是尚未投入足够技术，而非逻辑失效。

主目标仍是原命题的证明或证否。提前停止只允许：

- 完整闭合原题；或
- 得到改变已知渐近阶、主指数、核心子问题状态的严格定理，经过另一工作流敌对
  数学 QA，且初步查重后足以担当独立 SCI 二区候选论文的主定理。

有限扫描、条件性路线、单个局部引理、方法 no-go 和小常数改进均不能触发提前
停止。
