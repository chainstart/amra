## 2. #776 公式独立核对

### 2.1 原始与加强起点

由 N=r+5、M=N-2=r+3 得 r=M-3，且

\[
{N\choose3}-r-\left({N\choose3}-(N-2)\right)=3.
\]

原始起点确比 Round11 加强起点多 3。其 first raise 把 canonical 尾项 \({3\choose1}\) 送成 \({3\choose2}=3\)，故首个互补 defect 是 M-6。该接口与 REPORT 的 (3)--(5) 一致。

### 2.2 增长余量

对 M=14 到 180，脚本从 canonical 贪心展开直接重算 D、E，并逐点核对

\[
D_{M-4}-E_{M-4}=6,
\]

\[
D_{M-5}-E_{M-5}=M+4,
\]

\[
D_{M-6}-E_{M-6}={M-7\choose2}+4M-21.

这些是全参数纸面展开式的有限回归审计，而不是无限量词的计算证明。REPORT 对证据等级的表述正确。

### 2.3 Round11 的减一勘误

独立代入 M=30：加强 defect 的对应值为 405，canonical 展开为

\[
{28\choose26}+{26\choose25}+{24\choose24},
\]

其上升量为 29，悬挂后为 434。因此 Round11 展示式两边应分别是 \({M-1\choose2}-1\) 与 \({M\choose2}-1\)。遗漏的同一个 -1 不破坏两侧的悬挂等式，所以这是一处局部展示算术错误，不会使 Round11 的 M=75000 加强命题反例失效，更不会使原题转成已否定。

### 2.4 原始端点与二次 slack

脚本以三条实现路径交叉核对：普通 canonical 递推、run-length 压缩递推、lazy-carry 递推。在 9≤M≤180 的 172 个点上三者的 E3 相同；同时从原始正向容量独立核对

\[
a_{N-2}\ge0
\iff E_3\le {M-1\choose3}+28.
\]

同一范围也核对了二次 slack 递推与 defect 递推的逐层对偶。M=75000 的精确点给

\[

\]

故相对原始允许值 +28 尚余 23。此结果只排除“Round11 的同一点也反驳原始起点”这一错误推断；它不是 all-M 证明。

首次 carry 前的正规形也可逐项审计。以 V=M-3、x3=5、x_(j+1)=C(x_j,2)-2j+3，REPORT 的展开在 x_j<V-2j+5 时确为严格降序的 canonical 展开；一次 Pascal 分裂直接给下一项。标量轨道 5、7、16、113、6319、19961710 复算无误。阈值失败以后该展开必须重新 canonicalize，REPORT 没有越过阈值继续套公式。

更一般地，I_j=[x_(j-1)+2j-6,x_j+2j-5] 的右端与 I_(j+1) 左端相差恰1，且 x_j 递增无界，所以这些区间分割全部 V≥7。在 I_j 上，最后一个合法阈值与第一个失败阈值由区间定义逐式给出；Pascal 合并后的 y_j 在左端距下一 rank-3 顶项容量为 2x_(j-1)+2j-6>0，随后只会增大。因此首次 carry 的全参数分区及 post-carry 公式不是有限模式外推。

对 6329≤V≤19961721，第一次失败固定发生在 rank 8。恒等式 C(V-10,3)+C(V-11,2)+19961710=C(V-9,3)+y（y=19961710-(V-11)）正确；在区间左端 C(V-9,2)-y=12648，且该差随后递增，所以 y 的 2-canonical 顶项严格低于 V-9。由此 REPORT 的首次 carry 区间正规形是全区间代数结论；脚本的五个代表点只是回归核对，不承担无限区间证明。

### 2.5 rank-5 固定门槛归约

令

\[
B_q={V+1\choose q}+{V\choose q-1},\qquad
F_q={V+1\choose q}+{V-1\choose q-1}+{V-2\choose q-2}.
\]

独立 Pascal 展开给 \(F_q=B_q-{V-2\choose q-3}\) 及
\(\operatorname{KK}_q(F_q)=F_{q-1}\)。因此 \(F\) 只是不含每层
\(+V\) 的调和屏障；它本身不是原递推不变量。REPORT 对这个符号缺口的
警告正确。

置 \(h=E_5-F_5\)。若 \(0\le h<{V-2\choose2}\)，严格的 cap 分离使
两次下影可逐项计算为

\[
E_4=B_4+2+\operatorname{KK}_2(h),
\]

\[
E_3={V+2\choose3}
 +\operatorname{KK}_2\!\left(2+\operatorname{KK}_2(h)\right).
\]

rank-2 断点 \(\operatorname{KK}_2(w)\le t\iff w\le{t\choose2}\)
连续使用两次，确实得到 excess 不超过 28 当且仅当
\(h\le{376\choose2}=70500\)。在等号处中间 residual 为378、最终
excess 为28；加一后分别为379与29。对 \(V\ge379\)，这两个测试点都
严格低于 cap \({V-2\choose2}\)。

其余两支也覆盖完整：\(h\le0\) 由单调性给最终 excess 至多3；
\(h\ge{V-2\choose2}\) 则 \(E_5\ge B_5\)、\(E_4\ge B_4+V\)，最终
excess 至少 \(\operatorname{KK}_2(V)\ge29\)。因此 REPORT 的

\[
E_3\le{V+2\choose3}+28\iff E_5-F_5\le70500
\quad(V\ge379)
\]

是全参数纸面归约。尚未证明的是右侧的统一界；有限样本很小不能替代该步。

再令 \(g=F_6-E_6\)。在 \(0\le g\le{V-2\choose4}\) 的合法尾补区间，
独立应用

\[
{V-2\choose3}
-\operatorname{KK}_4\!\left({V-2\choose4}-g\right)
=U_{V-6}(g)
\]

得到 \(h=V-U_{V-6}(g)\)。若 \(g<0\)，则 \(E_6>F_6\)，单调性给
\(h\ge V>70500\)，所以自动失败。若 \(g>{V-2\choose4}\)，则
\(E_6<F_6-{V-2\choose4}\)，再次由单调性给
\(h\le V-{V-2\choose3}<70500\)，所以自动成功；等号
\(g={V-2\choose4}\) 仍在尾补恒等式内。故 \(V\ge70501\) 时上述固定
门槛在全部三个分支上又等价于

\[
g\ge\operatorname{KK}_{V-5}(V-70500)
 ={V-4\choose2}-{70496\choose2}.
\]

末项等号来自 \(V-70500\) 个对角单位从 lower rank 70496 排到
\(V-5\)，索引无 off-by-one。该式只是把剩余任务变成显式二次下界；
REPORT 没有声称已经证明它。在边界 \(V=70501\)，目标数为1，其
rank-\(70496\) 下影恰为70496，与右侧二次差一致。\(V=70500\) 时
\(V-70500=0\)，但 \(g<0\) 分支可能落在下影平台，故 REPORT 没有把
二次等价式外推到该点，而是仍由 rank-5 的 (14s) 覆盖。

## 3. #256 定理独立核对

### 3.1 前提链

审计使用严格不等式 E(A)<6m。结合既有 E(A)≥2mS_p(Q_p) 及整数 S_p(Q_p)≥2，确实强制 S_p(Q_p)=2；随后 primitive p 投影具有恰两个非零位置。若把前提错写成 E≤6m，则这一步不成立；REPORT 保留了严格不等式。

### 3.2 必要性

对奇素数 p，令 G=(Z/pZ)^×/{±1}。两点群环恒等式在每个 Galois 嵌入下给 log-sine 卷积等式。G 的非平凡字符正好对应非主偶 Dirichlet 字符；其 log-sine Fourier 系数由非零 Gauss 因子及 L(1,χ) 构成，而 L(1,χ)≠0。因此除主模外所有 Fourier 模均消失，h 必为常函数。再由总质量 s-1=t(p-1) 得常数 2t，推出一类 2t+1、其余各类 2t。

边界检查：p=3 时 G 为单点，结论直接由总质量得到；p=2 不受该奇素数定理覆盖；t=0 时 s=1，与公式一致。重复指数只进入计数，没有被错误排除。

### 3.3 充分性与 primitive-projection no-go

任意 orientation 下，恒等式

\[
1-\zeta^{-a}=-\zeta^{-a}(1-\zeta^a)
\]

把每个 signed class 的 2t 个因子换向为根单位乘积；所有类合起来给 p^t，再乘 distinguished class 的额外一个因子。所得等式在 ζ 与 1 处同时成立，整数多项式之差因而被 (x-1)Φ_p(x)=x^p-1 整除。这验证了 REPORT 的 iff，而不仅是必要条件。

因此只看 primitive p 投影无法排除所有低能量模式：这些直方图确实可实现。p=5、residues (1,1,1,2,2) 的直接循环卷积给 5x^3(1-x)，例子正确。

多素数 CRT no-go 的量词也正确：对任意有限奇素数集及 n 大于其中最大素数，每个 p 的边缘列可取 n-p 个零、一个 signed class 3 个、其余各 2 个；非零总数为 p，对应 t=1。把各列按同一组 n 个标签排列后逐标签使用 CRT，即同时实现全部边缘。该构造只否定“边缘计数自行矛盾”，并未声称构造具有低能量；REPORT 保留了这个关键限定。

t=0 时 s=1。写 A=(pc_1,...,pc_m,b)、p不整除b 后，B(z^p) 与 z^bB(z^p) 落在两个互异 residue fibres，故系数平方和精确相加为 E(A)=2E(c_1,...,c_m)。这一步不依赖渐近估计，但仍只处理一条递归分支。

### 3.4 有限程序审计

脚本穷举 p=3,5,7、外部多重集大小 1 到 8，共 3,540 例：实际 two-support 162 例，直方图 iff 预测 162 例，零失配。

另对 3≤n≤7、1≤a_i≤9 的指数多重集检查 29,866 个非平凡素数分裂：89 个满足 E<6m，其中 25 个为奇素数分裂，直方图规则零反例。有限统计不承担全参数证明。
