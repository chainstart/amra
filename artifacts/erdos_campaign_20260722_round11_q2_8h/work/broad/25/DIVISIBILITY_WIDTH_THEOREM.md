# Erdős #25：随 cutoff 重分链的整除宽度定理

日期：2026-07-22（Asia/Hong_Kong）

状态：**定理与证明正确，但经第十一轮敌意复核发现其结论已被“全局删冗余
+ 可和倒数尾”特例蕴含；是方法性重证明，不计作新增覆盖范围。原题仍开放。**

## 1. 定理

设 `n_1<n_2<...`，每个模数 `n_i` 指定任意剩余类 `a_i mod n_i`，并按
Erdős #25 的激活规则定义

\[
 A=\{m\ge1:\ m<n_i\text{ 或 }m\not\equiv a_i\pmod {n_i}
       \text{ 对每个 }i\}.
\]

令 `P_X={n_i:n_i<=X}`，以整除为偏序，并令 `w(X)` 为有限偏序 `P_X` 的宽度，
即其中最大两两不可比子集的大小。若

\[
 \boxed{
 \limsup_{X\to\infty}{w(X)\log\log X\over\log X}<1,}
 \tag{1}
\]

则 `A` 的自然密度存在。

更精确地，若 `P_X` 的某个链分割具有链内有效原子数
`s_1(X),...,s_h(X)`，且

\[
 \boxed{\prod_{j=1}^h(1+s_j(X))=o(X),}             \tag{2}
\]

则结论成立。条件 (1) 是 (2) 的一个内蕴、易检验充分条件。

与第十轮不同，这里**不需要预先固定一个无限链分割**；每个 cutoff `X` 可以
重新选择最优链分割。宽度 `w(X)` 因而是模数族本身的性质，而不是额外数据。

## 2. 单个 cutoff 的链原子化

固定 `X`。模数 `n_i>X` 对 `[1,X]` 完全尚未激活，可以忽略。由有限
Dilworth 定理，把 `P_X` 分成恰好 `w(X)` 条整除链。固定其中一条链

\[
 n_1'\mid n_2'\mid\cdots.
\]

若两个完整剩余类相交，后一个细类包含于前一个粗类；相应激活阈值还满足
`n_t'>=n_s'`，故细激活片也完全包含于粗激活片，可以删除。删完后，同一链
的完整剩余类两两不交，激活片也两两不交。记该链剩余有效原子数为 `s_j(X)`。

严格整除的正整数每一步至少倍增，所以统一有

\[
 s_j(X)\le1+\log_2X.                                \tag{3}
\]

## 3. 全容斥只有乘积多个原子项

把每条链内的删除集视为其不交原子之并，再对各链作有限容斥。每个容斥项在
每条链中或者不选原子，或者选恰好一个原子，因此包括空项在内的总项数至多

\[
 T_X:=\prod_{j=1}^h(1+s_j(X)).                      \tag{4}
\]

跨链选出的一个原子元组若同余条件不相容，交为空；若相容，广义 CRT 给出模

\[
 L=\operatorname{lcm}(n_{j,i_j})
\]

的一个完整剩余类，并附加激活阈值
`M=max_j n_{j,i_j}`。因为 `M<=L`，其 `[1,X]` 计数为

\[
 {X\over L}+O(1),                                   \tag{5}
\]

且 `O(1)` 对 cutoff、链分割和元组完全统一。把 (5) 对所有容斥项求和，得到

\[
 { |A\cap[1,X]|\over X}=\delta_X+O(T_X/X),          \tag{6}
\]

其中 `delta_X` 是避开全部 `n_i<=X` 的**完整**剩余类所得有限周期系统的
自然密度。这个主项由有限系统本身唯一决定，与本次选择哪一个链分割无关。

## 4. 单调极限完成证明

随 `X` 增大，有限周期系统只会加入新的禁剩余类，所以

\[
 1\ge\delta_X\downarrow\delta\ge0.                 \tag{7}
\]

若 (2) 成立，(6)--(7) 立即给

\[
 |A\cap[1,X]|/X\longrightarrow\delta.
\]

现在验证 (1)。按有限 Dilworth 取 `h=w(X)`，由 (3)--(4)，

\[
 T_X\le(2+\log_2X)^{w(X)}.
\]

而

\[
 \log T_X
 \le w(X)(\log\log X+O(1))
 \le(c+o(1))\log X
\]

对某个固定 `c<1` 成立。因此 `T_X<=X^{c+o(1)}=o(X)`，即 (2)。证毕。

## 5. 为什么 cutoff 重分链是合法的

第十轮 QA 曾为缓增链数版本要求“预先固定链分割”，以避免未来细类改变早期
原子。这里无需该要求，原因是 (6) 对每个 `X` 都从**同一个实际有限系统**
重新精确展开：

1. `delta_X` 是该有限系统的周期密度，与表示方式无关；
2. 左边也是原 survivor 在 `[1,X]` 的真实计数；
3. 链分割只用于给这一时刻的误差项数找上界；
4. 下一个 cutoff 可以采用完全不同的分割，因为极限由表示无关且单调的
   `delta_X` 承担，而不是由某组链原子的逐项极限承担。

所以不存在跨 cutoff 的原子一致性缺口。

## 6. 边界与价值

- 形式上，该定理把“存在一个缓增固定链分割”提升为内蕴的有限整除宽度
  条件，并把第十轮的 `o(log X/log log X)` 放宽到临界常数以下；
- 任意两两不可比的模数族有 `w(X)=|P_X|`，可能远大于该阈值，所以原题没有
  闭合；
- 证明没有假定跨链模数互素，也没有使用无限容斥；
- **重要降级：**先全局删除其完整类已包含在某个更早完整类中的模数。每个
  剩余类在任一链原子化中都必须保留。条件 (1) 因而给有效模数计数

  \[
  R(X)\le w(X)(1+\log_2X)=O((\log X)^2/\log\log X).
  \]

  按 dyadic 块求和立即有 `sum 1/n_i<infinity`。更一般的 (2) 中，非空链数
  至多 `log_2 T_X=O(log X)`，每链至多 `O(log X)` 个原子，同样给
  `R(X)=O((log X)^2)` 和倒数和收敛。因此两项结论都可由已知可和尾定理推出。
  cutoff 重分链的容斥证明仍是正确的，但**不能计作新的密度子类或投稿主结果**。

下一目标不是继续微调常数 1，而是进入不强迫倒数和收敛的区域：利用 CRT
不相容性把 (4) 的全部元组数替换为实际相容元组数，或用 first-kill novelty
对高宽度链间交叉项收费。
