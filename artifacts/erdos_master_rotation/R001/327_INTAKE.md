# Erdős #327（第二问）— R001准入研究

日期：2026-07-23
终态：`STRICT_NEW_REDUCTION__ONE_DEEP_DENSITY_AUDIT_RECOMMENDED`

## 目标

只研究第二问：是否每个

\[
A\subseteq[1,N],\qquad a\ne b\in A\Rightarrow a+b\nmid2ab
\]

都满足 `|A|=o(N)`。要证否它，只需构造一个正下密度独立集。

## 边的精确参数化

设 `a<b`，写

\[
a=gx,\qquad b=gy,\qquad (x,y)=1,\qquad x<y.
\]

因为 `(x+y,xy)=1`，

\[
a+b\mid2ab
\iff x+y\mid2g
\iff q:=\frac{x+y}{(x+y,2)}\mid g.
\]

写 `g=tq`，则该边的两个端点是 `tqx,tqy`。

进一步，所有“较大原始端点” `qy` 恰好是

\[
rs,\qquad (r,s)=1,\qquad r<s<2r,\qquad s\ {\rm odd}.
\]

证明分两支：

- 若 `x+y` 为奇数，则 `q=x+y`，取 `r=y,s=q`；
- 若 `x+y` 为偶数，则互素性迫使 `x,y` 都为奇数，取
  `r=q=(x+y)/2,s=y`。

反过来，给定这样的 `r,s`，令

\[
x=2r-s,\qquad y=s,\qquad q=r.
\]

则 `0<x<y`、`x,y` 为互素奇数，且 `qx,qy` 构成一条边，较大端点正是
`rs`。

## 一个新的全局独立集

令

\[
\mathcal F=\{n\ge1:\text{不存在 }rs\mid n,
(r,s)=1,\ r<s<2r,\ s\text{ 为奇数}\}.
\]

若 `a<b` 是一条边，上述参数化说明 `b` 必被某个这样的 `rs` 整除。因此
`\mathcal F` 中不可能有边；`\mathcal F\cap[1,N]` 对每个 `N` 都是原问题的
合法集合。

这把一条证否路线压成明确的乘法数论命题：

> 若能证明 `\mathcal F` 具有正下密度，则#327第二问为否。

## 可复现实验

`analyze_327_near_square_sieve.py`：

1. 枚举全部 `rs<=10^6`；
2. 筛去其倍数；
3. 对每个原始基数反向构造一条边；
4. 对 `N<=2000` 穷举核对剩余集合确为独立集。

得到的密度为：

| N | `|\mathcal F\cap[1,N]|/N` |
|---:|---:|
| 1,000 | 0.608000 |
| 5,000 | 0.577000 |
| 20,000 | 0.560150 |
| 100,000 | 0.542620 |
| 500,000 | 0.529322 |
| 1,000,000 | 0.523847 |

密度缓慢下降，不能据此宣称正极限。禁止基数倒数质量也缓慢增长，所以简单
并集界不能闭合。

## 与现有结果的关系

论坛中的最新上界 `f_2(N)<=(0.7630+o(1))N` 来自 smooth–rough 分解和有限
优化证书；它没有回答 `o(N)`。现有有限最优解在 `N<=1000` 仍约为
`0.69N`，同样不能外推。

本归约与“整数在 `(y,2y]` 中有除数”的Ford理论相邻，但多出三个结构条件：
乘积 `rs` 本身只需整除 `n`、`r,s` 互素、较大因子为奇数。不能直接引用
普通短区间除数定理断言 `\mathcal F` 密度为零或为正。

## 晋级判断

建议只晋级一个4小时深攻周期，目标限定为：

1. 用Ford型乘法表/短区间除数方法确定 `\mathcal F` 的密度是否为零；
2. 若为零，尝试对每个禁止倍数类做带权选择，而不是完全删除其所有倍数；
3. 若能证明正下密度，则立即得到#327第二问的完整反例。

本轮没有声称原题闭合，闭合距离暂保持3；严格新增成果是边的近平方互素因子
参数化和一个可直接分析的全局独立集。
