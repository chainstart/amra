- 闭合距离保持3，只在出现高阶碰撞矩或可迭代构造后重新准入。

### #327第二问：晋级一次解析密度审计

- 边的较大本原端点被精确刻画为
  `rs`，其中 `(r,s)=1`、`r<s<2r` 且 `s` 为奇数；
- 不被任何此类 `rs` 整除的整数构成一个对所有 `N` 严格独立的全局集合；
- 该集合在 `N=10^6` 的有限密度为 `0.523847`，但有限数据不能证明正下密度；
- 下一步限定为一次4小时Ford型乘法表/短区间除数审计，闭合距离暂保持3。

证据见 `327_INTAKE.md` 与 `327_near_square_sieve.json`。
