# R003 主线程准入组

本组对 #145、#1097、#65、#187、#238、#241、#738、#531 执行标准
准入动作。每题均以原始命题为目标，但本组没有把阶段引理、路线排除或有限
检验冒充原题闭合。

本轮最明确的推进是：

- #145：把 Chan 方法在 \(\gamma=15/4\) 的首个断点精确定位为同一
  \(H=x^{3/17}\) 幂尺度两侧相差 \(\log^{29}x\) 的未覆盖窗口；
- #187：把 van der Waerden 阶梯定量化为一个五重迭代对数下界；
- #531：构造一族使 BENTW 单集合概率界逐项取等，严格排除“只改进该
  概率界”这一延伸路线；
- 其余五题分别取得精确的候选族计算、等价硬核复核或对准入路线的严格
  反例。

这些结果都不足以闭合相应原题，也没有登记为论文级候选。
