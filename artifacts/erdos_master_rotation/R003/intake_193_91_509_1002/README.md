# R003 标准准入组 C：#193、#91、#509、#1002

本目录完成四题的首次正式准入：官网状态和原始题面刷新、一手来源核对、
closing lemma、最小可检验尝试、首个失败断点与晋级判断。所有四题仍开放，
本轮没有把有限计算、已知子情形或紧性证据写成原命题闭合。

核心结论：

- **#193**：三步集情形及长度 8 的三字母 Parikh 证书是
  Gerver--Ramsey 1979 Theorem 3 的已知内容；真正断点从四步秩 3 的
  加权 Parikh 核开始。
- **#91**：独立核验官网评论中的自然密度 1 部分结果；原题精确缩到每个
  \(f\)-平台最后三个规模。队列中的“有界平台间隙”即使成立也不能处理
  这些末端，路线需重置。
- **#509**：两个相同 MST 边长的三根配置可以分别产生连通和不连通
  lemniscate，严格否决“只按两条 MST 长度分类”；必须加入夹角、第三边
  或三次式临界值。
- **#1002**：Farey cell 精确积分支持 \(1/A\) 尾界，却证明统一二阶矩
  路线不可能；Ostrowski 块取绝对值还会多出 \(\log\log n\)，需要重尾
  数字间的符号抵消。

没有一项达到 SCI 二区发表级别，也没有一题晋级为完整证明候选。详见四份
`*_REPORT.md`、`RESULT.json` 与对应验证证书。
