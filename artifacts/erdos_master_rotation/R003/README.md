## 闭合结论：#522

2026-04-20 的旧证明稿有致命的跨次数耦合错误：对倒数多项式 \(Q_n\)，
固定 \(n\) 的同分布不能推出跨 \(n\) 的块插值；事实上任意 \(m>n\) 时
归一化 \(L^2\) 距离的期望恰为 2。

Przemek Chojecki 2026-04-27 的署名修订稿删去了该步骤，改为在同一个前缀
过程 \(P_n\) 上控制内、单位和外三个半径。主审与未参与主审的独立代理均
逐项复算了块插值、四维协方差、Nazarov--Nishry--Sodin 输入、小值截断、
Borel--Cantelli 指数以及三半径 Jensen 挤压，确认它证明
\[
R_n=\frac n2+O_\omega(n^{399/400})\qquad\text{almost surely}.
\]
这与原题的同一无限 Rademacher 序列、全 \(n\)、闭圆盘及重数计数完全
匹配。因此中央账本登记为 `closed_verified`，证据层级是“公开署名完整
预印本、独立核验”；官网状态、同行评审和形式化仍保持未确认。
