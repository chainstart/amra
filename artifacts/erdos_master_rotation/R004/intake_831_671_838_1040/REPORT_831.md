# Erdős #831：固定半径局部结构与一般位置路线审计

## 结论先行

- 官网状态：`OPEN`（2026-07-24 抓取）。
- 当前严格下界仍是
  \[
  h(n)\ge\frac{n-2}{2}.
  \]
- 2026-06-16 官网评论给出一条公开的上界草证
  \[
  h(n)\le n^2\exp(O(\sqrt{\log n})).
  \]
  本轮补核其投影、格点和体积常数链，未发现实质错误；它是当前很值得正式写成论文的
  阶段结果，但不是本轮首次公开。
- 本轮没有闭合 #831。固定半径路线的首断点可精确识别为另一个开放的
  Erdős #104（一般位置版本）：\(n\) 点能确定多少个至少过三点的全等圆。
- 纯三图局部禁形不能改善线性下界；真实进展必须使用“全等圆可实现性”，而不只是
  每对点的码度至多二。

## 冻结题面

\(h(n)\) 是满足下述性质的最大整数：任取平面上 \(n\) 个点，且无三点共线、无四点
共圆，由三点确定的三角形至少出现 \(h(n)\) 个不同外接圆半径。问题要求估计
\(h(n)\) 的增长。

Martínez--Roldán-Pensado 2014 证明：充分多点中存在 \(k\) 点，使其全部
\(\binom k3\) 个外接半径互异，并给出阈值 \(n_k=O(k^9)\)。这修补了 Erdős 原证明的
Bézout 缺口；它只推出 \(h(n)=\Omega(n^{1/3})\)，弱于下面的线性双计数。

## 路线 A：固定半径三图

固定 \(R>0\)，令 \(H_R\) 的顶点为给定点集，边为外接半径恰为 \(R\) 的三元组。
对任意点对 \(\{a,b\}\)，半径 \(R\) 且经过 \(a,b\) 的圆至多两个。无四点共圆保证
每个圆至多贡献一个第三点，故
\[
 d_{H_R}(a,b)\le2.
\]
于是
\[
 3|E(H_R)|=\sum_{\{a,b\}}d_{H_R}(a,b)
 \le2\binom n2,
\qquad
 |E(H_R)|\le\frac23\binom n2=\frac{n(n-1)}3.
\]
对全部 \(\binom n3\) 个三角形按半径分桶即得
\[
 h(n)\ge
 \frac{\binom n3}{n(n-1)/3}=\frac{n-2}{2}.
\]

### 与 #104 的精确关系

把每个原点 \(p\) 对偶为以 \(p\) 为圆心、半径 \(R\) 的圆 \(\Gamma_p\)。一个
\(R\)-外接圆的圆心正是三条 \(\Gamma_p\) 的公共交点。另一方面，在原平面中，
一个 \(R\)-外接圆就是一条经过至少三给定点的半径 \(R\) 圆。由于无四点共圆，
每条这样的圆恰对应一个 \(H_R\) 边。

缩放 \(R\) 到一，\(|E(H_R)|\) 正是 Erdős #104 所研究的“\(n\) 点确定的至少过三点
单位圆数”，这里还带一般位置条件。#104 的不加一般位置版本目前只知
\[
 \Omega(n^{3/2})\le \max |E(H_R)|\le O(n^2),
\]
并猜测 \(o(n^2)\)；其 \(\Omega(n^{3/2})\) 构造是否满足 #831 的全部一般位置条件
不能自动假定。Erdős 另外猜测一般位置时的上界为 \(O(n^{3/2})\)。

所以：

- #104 的 \(o(n^2)\) 会立即把 #831 的下界提升为 \(h(n)=\omega(n)\)；
- #104 的一般位置 \(O(n^{3/2})\) 会给 \(h(n)=\Omega(n^{3/2})\)；
- 继续从“每对至多两个第三点”做局部计数，等价于原地重撞 #104 的已知屏障。

## 局部禁形为何不够

### 可实现的四点饱和块

取
\[
 A=(0,0),\quad B=(4,0),\quad C=(1,2),\quad H=(1,3/2).
\]
\(H\) 是 \(\triangle ABC\) 的垂心。精确计算给出四个三角形
\[
 ABC,\ ABH,\ ACH,\ BCH
\]
的外接半径平方都为 \(65/16\)。四点无三共线，四点共圆判别行列式为 \(12\ne0\)。
因此 \(H_R\) 在这四点上就是 \(K_4^{(3)}\)，每个点对码度恰为二，并精确达到
\[
 4=\frac23\binom42.
\]
所以把 \(K_4^{(3)}\) 当作禁形是错误的。

### 组合上甚至可无 \(K_4^{(3)}\) 地饱和

证书脚本列出 \(v=6,7\) 的二重三元设计：每个点对恰出现在两个三元组中，边数分别
为 \(10,14\)，达到码度双计数上限，而且都不含 \(K_4^{(3)}\)。这证明任意只使用
“码度至多二 + 禁止四点局部完全块”的纯三图论证仍不能产生固定比例缺口。

证书还核对了一个更精确的局部正规形：这两个设计中每个顶点的 link 都是单个
\(C_{v-1}\)（分别为 \(C_5,C_6\)）。在对偶的全等圆排列里，一个假想实现会让每对
圆的两个交点全部并入三重交点，而每条圆上的三重交点按这个 link cycle 配对。
因此下一步可把“各圆上的实际循环次序是否能同时实现”做成有限符号/有向拟阵约束；
仅知道 link 为环仍不是不可实现证明。

### 六点饱和设计的短符号矛盾

本轮还从 link cycle 提取出一个不依赖数值搜索的六点不可实现证书。把半径缩放为一，
令 \(p_0=0\)。记含 \(0\) 的五条三元边
\[
012,\ 024,\ 045,\ 035,\ 013
\]
的圆心依次为 \(a,b,c,d,e\)。这些圆心都在单位圆上。对任意一对点 \(0,p_i\)，
两条单位圆的两个圆心关于弦中点对称，故两圆心之和为 \(p_i\)。沿 link
\(1-2-4-5-3-1\) 得到
\[
 p_1=a+e,\quad p_2=a+b,\quad p_4=b+c,\quad
 p_5=c+d,\quad p_3=d+e.
\]

边 \(125\) 的圆心是 pair \(12\) 的另一个圆心，因而为
\[
 p_1+p_2-a=a+b+e.
\]
它到 \(p_5\) 的距离为一，所以
\[
 |a+b+e-c-d|=1.
\]
同理，利用边 \(235\) 和已知边 \(035\)，得到
\[
 |c+d+e-a-b|=1.
\]
令 \(X=a+b-c-d\)。两式为
\[
 |X+e|=|-X+e|=1,\qquad |e|=1.
\]
平方后相加给 \(2|X|^2=0\)，故 \(X=0\)，但这又给
\(p_2=a+b=c+d=p_5\)，与六点互异矛盾。证书脚本精确验证了最后的多项式恒等式。

因此该 \(2\)-\((6,3,2)\) 饱和设计确实不能由同半径三角形实现。更广泛地，
Harborth--Mengersen 1986 已确定六点、七点最多分别只有 \(8,12\) 个全等圆。
恰恰是从组合设计到全等圆实现之间的差，才是应继续提取的几何约束。这个六点引理
仍不足以改善渐近界：近饱和的高阶二重设计可以避开单个有限配置，尚需一族可计数的
几何禁形或稳定性定理。

## 路线 B：符号圆选择与一般位置

对每个距离小于 \(2R\) 的点对 \(a,b\)，恰有两个半径 \(R\) 圆经过它们。可以把
一个三角形边标记为它对三个边所选择的圆支。一个真实三角形要求三个边支对应同一
圆心；若同一点对出现在两个 \(H_R\) 边中，无四点共圆又要求两边使用相反的两个圆。

这把问题转成：

> 哪些码度至多二的三图，能由一族全等圆的三重交点实现，同时没有四重交点？

该“圆支一致性”是纯三图模型遗漏的约束。对六点饱和设计做单核非线性代数搜索时，
所有找到的零残差解都落入“六点同圆”的禁用分支；这与已知 \(f(6)=8<10\) 一致，
但数值搜索本身不作为不可实现证明。可证明的下一步应是：

1. 对最小饱和设计建立消元理想；
2. 用四点共圆行列式作饱和，排除共圆分支；
3. 提取可推广的低阶圆支恒等式，而不是把一次 Gröbner 计算误当成渐近证明。

“一般位置”只能排除共线/共圆两个代数退化族，不能擅自增强为坐标代数独立。随机
扰动会摧毁重复半径等式，因而也不能用“通用扰动保持 \(\Theta(n^2)\) 个等式”。

## 当前上界草证的独立核对

2026-06-16 Sam Korsky 的官网评论从高维抛物面格点
\[
 S_{m,R}=\{(x,\|x\|^2):x\in\mathbb Z^m\cap RB_m\}
\]
出发。它无三点共线；有限点集的通用线性投影可同时避开平面中的三点共线和四点共圆。
相同平移类的有序三元组投影后仍为平移，故外接半径相同。

一个平移类由
\[
 u,\ v,\ \|x+u\|^2-\|x\|^2,\ \|x+v\|^2-\|x\|^2
\]
决定，后两个整数各只有 \(O(R^2)\) 个值。可行 \((u,v)\) 落在
\[
 D_m=\{(u,v):\exists y,\ y,y+u,y+v\in B_m\}.
\]
若三点都在单位球中，则方差恒等式给出
\[
 \|u\|^2+\|v\|^2+\|u-v\|^2\le9.
\]
对应二次型每个坐标块的行列式为 \(3\)，所以
\[
 \operatorname{vol}(D_m)
 \le\operatorname{vol}(B_{2m})\,3^{3m/2}
 =\operatorname{vol}(B_m)^2
   \left(\frac{3\sqrt3}{2}\right)^m e^{o(m)}.
\]
结合格点覆盖估计和 \(N=|S_{m,R}|=R^m\operatorname{vol}(B_m)e^{o(m)}\)，得到
\[
 \tau(S_{m,R})
 \le N^2\left(\frac{3\sqrt3}{2}\right)^mR^4e^{o(m)}.
\]
令
\[
 m\sim2\sqrt{\frac{\log n}{\log(3\sqrt3/2)}}
\]
即得
\[
 h(n)\le n^2\exp\!\left(
 4\sqrt{\log(3\sqrt3/2)}\,\sqrt{\log n}
 +o(\sqrt{\log n})\right).
\]
本轮未发现这条推导的断点；正式成文时应补足通用投影的非恒零判别和格点膨胀误差。
