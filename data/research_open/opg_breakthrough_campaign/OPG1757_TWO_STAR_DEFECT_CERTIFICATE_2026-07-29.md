# OPG-1757：两颗任意基图星顶点的全域证书

日期：2026-07-29

## 结论

固定基图 <code>H?&#96;bM~^</code>、继承边对索引 `(0, 2)`、重复假孪生邻域
`S={1,5,6,7,8}`。在基图上再加入两颗互不相邻的星顶点，它们的
邻域可以是任意 `R,Q⊆{0,…,8}`，允许 `R=Q`；随后加入任意数量
`t≥0` 的 `S`-假孪生点。所有新增顶点之间都没有边。

对全部

```text
512 * 513 / 2 = 131328
```

个无序邻域对 `{R,Q}`，继承边对始终满足森林负相关不等式。没有找到
反例，而且结论覆盖每个整数 `t≥0`，不是有限范围的空搜索。

严格作用域：

- 只证继承边对 `(0,2)`，对应基图边 `(0,4)` 与 `(2,5)`；
- 没有检查扩展图的全部边对；
- 没有声称这一整族图对所有边对都满足猜想；
- 不允许任意星顶点连接重复假孪生点，也不允许新增顶点之间有边。

## 精确算法

独立 C++ 内核首先枚举基图的全部 `2^19` 个边子集，用并查集保留森林，
建立四个通道：

```text
N, N_e, N_f, N_ef.
```

基图分布包含 3430 个分区，通道总数独立复现为：

```text
(54124, 19726, 21496, 7834).
```

对每个基图分区，内核枚举两颗星实际选择的边集 `(A,B)`。先要求 `A`
在当前分区块上单射，再要求 `B` 在 `A` 合并后的分区块上单射。合法
精确边集对总数为：

```text
20823456.
```

随后在 `A`、`B` 两个九位掩码维度分别做子集 ζ 变换，一次得到全部
有序 `(R,Q)`；内核逐项验证交换对称性，然后只输出规范次序
`0≤R≤Q<512` 的 131328 行。

## 为什么五个值给出全 `t` 证明

对固定的五点邻域 `S`，假孪生转移写成 `T_S=6I+N`。恒等部分来自
空集和五个单边选择。`N` 的每次非零转移至少合并两个当前 `S`-分区
块，因此严格减少 `S` 占据的块数；最多只有五个这样的块，所以

```text
(T_S - 6I)^5 = 0
```

在每个九点基分区上恒成立。

因而四个计数均具有精确形式

```text
C_i(t) = 6^t / 1296 * Σ_{k=0}^4 d_{i,k} binomial(t,k).
```

边际

```text
M(t) = N_e(t)N_f(t) - N(t)N_ef(t)
```

则具有形式

```text
M(t) = 36^t / 1679616 * Σ_{k=0}^8 h_k binomial(t,k).
```

对全部 131328 个邻域对，精确重算均得到 `h_0>0` 且所有 `h_k≥0`。
由于 `binomial(t,k)≥0`（整数 `t≥0`），所以每个边际严格为正。

系数类别为：

| 类别 | 邻域对数 |
|---|---:|
| 九个 `h_k` 全部严格为正 | 83040 |
| 首个零系数为 `h_6`，其余无负数 | 6588 |
| 首个零系数为 `h_7`，其余无负数 | 41700 |
| 出现负系数 | 0 |

## 最接近反例的已认证前沿

在对全部 131328 个邻域对做精确比较的 `t=10000` 截面上，最大比率来自

```text
R={0,4}, Q={2,5}
```

即两颗新增星分别连接所考察两条继承边的两个端点。其四个计数闭式为：

```text
N(t) =
  6^t/216 *
  (29375 t^4 + 998050 t^3 + 12440557 t^2
   + 67370306 t + 133621056)

N_e(t) =
  6^t/72 *
  (3125 t^4 + 106750 t^3 + 1336975 t^2
   + 7270766 t + 14474592)

N_f(t) =
  6^t/144 *
  (5875 t^4 + 208070 t^3 + 2700425 t^2
   + 15196078 t + 31243104)

N_ef(t) =
  6^t/48 *
  (625 t^4 + 22250 t^3 + 290147 t^2
   + 1639762 t + 3384288).
```

其边际简化为：

```text
M(t) =
  3*36^t/4 *
  (25 t^5 + 1616 t^4 + 33749 t^3
   + 319228 t^2 + 1424790 t + 2449440) > 0.
```

比率 `rho(t)=N(t)N_ef(t)/(N_e(t)N_f(t))` 严格递增：清除正分母后，
`rho(t+1)-rho(t)` 的 12 次分子多项式全部 13 个系数严格为正。因此
它从下方趋近 1，但永不越过。相对缺口满足：

```text
1-rho(t) ~ (7776/734375) t^-3
          ≈ 0.010588595744680851 t^-3.
```

在 `t=10000` 时，精确比率仍小于 1，相对缺口约为：

```text
1.0583385296608627e-14.
```

全域精确截面最大值发生如下变化：

| `t` | 最大比率掩码对 |
|---:|---|
| 0, 1, 2, 4 | `(490,490)` |
| 10, 25, 100 | `(409,409)` |
| 187, 1000, 10000 | `(17,36)` |

这些是证书逐截面覆盖全部 131328 对后的精确最大值。探索计算还提示
包络可能在 `t=8` 和 `t=147` 换手，但当前 production 证书没有保存
“每个竞争者在整个区间都被支配”的全域交叉乘多项式，因此不把该区间
包络写成认证结论。所有邻域对的全 `t` 正边际结论不依赖这一包络判断。
