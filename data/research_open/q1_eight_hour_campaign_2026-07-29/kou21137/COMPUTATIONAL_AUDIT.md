# KOU-21.137 computational audit and recovery log

Date: 2026-07-29

## Claim being certified

Among every isomorphism type in the GAP SmallGroups library at 2-power orders
at most \(128\), classify the groups \(G\) satisfying all three conditions:

1. \(\exp(G)=8\);
2. the set \(\{g^2:g\in G\}\) is a subgroup;
3. that subgroup is nonabelian.

The expected catalogue cardinalities are:

| order | 1 | 2 | 4 | 8 | 16 | 32 | 64 | 128 |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| groups | 1 | 1 | 2 | 5 | 14 | 51 | 267 | 2328 |

The total audit scope is 2669 isomorphism types.

## Independent routes

### Route A: table-only Python/NumPy verifier

`enumerate_smallgroups_tables.g` is intentionally predicate-free.  GAP is
allowed to supply only:

- its version and SmallGroups package version;
- catalogue coordinates;
- the complete multiplication table for each group;
- a SHA-256 digest of the zero-based table bytes.

It does not tell Python the exponent, square values, closure result,
commutativity result, derived subgroup, or Frattini subgroup.

`verify_smallgroups_classification.py` then independently:

- requires exactly the declared catalogue counts and all 2669 groups;
- requires exactly one complete table for every catalogue coordinate;
- matches a GAP-side and Python-side hash for every table;
- verifies that every row and column is a permutation;
- finds a unique two-sided identity and unique two-sided inverses;
- verifies associativity for every ordered triple in every table;
- computes every element order and the exact exponent;
- computes the square-value set and checks inverse/product closure;
- checks whether the square-value set is nonabelian;
- constructs the subgroup generated by commutators;
- constructs the Frattini subgroup as the subgroup generated by squares and
  commutators (the standard \(G^2G'\) formula for finite 2-groups).

The full associativity workload is
\[
  \sum_G |G|^3
\]
ordered triples, including all \(2328\cdot128^3\) triples at order 128.
NumPy materializes both association orders as `uint8` arrays, but every entry
is compared; vectorization changes performance, not scope.

### Route B: native GAP predicates

`gap_predicate_crosscheck.g` independently uses GAP group objects and
predicates to calculate:

- exponent-eight count;
- exponent-eight groups whose square values are a subgroup;
- exponent-eight groups with noncommuting square values;
- the final hit IDs.

For every hit it additionally records the square, derived, Frattini, and
center IDs; equality checks; nilpotency class; generator rank; automorphism
order; abelian invariants; element-order distribution; central-series sizes;
and pc power/commutator vectors.

The certificate is written only if the per-order counts and ordered hit list
from Routes A and B agree exactly.

## Fail-closed recovery events

These events are retained because they demonstrate that the pipeline stopped
on transport or labeling ambiguity instead of silently accepting it.

### Recovery 1: wrapped row transport

An initial compact exporter wrote one textual row per multiplication-table
row.  GAP's default screen width inserted physical line breaks into long
order-128 rows.  The verifier rejected the malformed row envelope and emitted
no certificate.  The first recovery used one coordinate per line, eliminating
the ambiguity.  The final V2 exporter safely returns to row records only after
setting a very large GAP screen width and checking the exact field count.

### Recovery 2: leading-zero SHA-256 representation

The first coordinate-record rerun stopped at
`SmallGroup(32,26)` with:

```text
FAIL-CLOSED: GAP/Python multiplication-table hash mismatch
```

Inspection showed that GAP 4.12.1's `HexSHA256` had rendered a digest beginning
with zero as 63 hexadecimal characters:

```text
36e1fbdc4e3e80dfc28e2267900d0f8db30060d18a341be3de81da445ae9840
```

while Python used the conventional fixed-width 64-character form:

```text
036e1fbdc4e3e80dfc28e2267900d0f8db30060d18a341be3de81da445ae9840
```

The verifier now validates that the GAP field contains one to 64 lowercase
hexadecimal characters, left-pads it to 64 characters, and only then compares
the digest.  It still stops on every substantive mismatch.

### Recovery 3: mislabeled Frattini check

Code review before certificate completion found that a result field named
`frattini_equals_square_values` had mistakenly reused the already computed
derived-subgroup equality.  The whole run was stopped.  The verifier now
constructs
\[
  \Phi(G)=G^2G'
\]
from the raw table and records both its size and its actual equality with the
square-value set.  The independent GAP route separately computes
`FrattiniSubgroup(G)`.

### Recovery 4: overbroad Frattini theorem statement

An independent proof audit found that an early draft had asserted
\(\operatorname{Sq}(A\wr C_2)=\Phi(A\wr C_2)\) for every finite seed satisfying
the proper-square criterion.  The finite 2-group hypothesis is essential:
for \(A=S_3\), the criterion holds with \(P=A_3=A'\), and the square subgroup
equals the derived subgroup and has order 18, but the Frattini subgroup of
\(S_3\wr C_2\) is trivial.

The theorem draft now states:

- for arbitrary finite \(A\) with proper \(P\),
  \(\operatorname{Sq}(W)=W'\);
- only for finite 2-group seeds,
  \(\operatorname{Sq}(W)=W'=\Phi(W)\).

## Structural order-128 audit

`validate_order128_structure.g` is separate from the raw-table minimum-order
certificate.  It first constructs, from an explicit six-generator
presentation, the common quotient
\[
  Q\cong\operatorname{SmallGroup}(64,138)
\]
and checks its order, exponent, class, center, and derived-subgroup order.
It then traverses all 2328 order-128 groups and checks the exact equivalence
\[
\begin{aligned}
&\exp(G)=8\text{ and the square values form a nonabelian subgroup}\\
&\hspace{25mm}\Longleftrightarrow
|Z(G)|=2\text{ and }G/Z(G)\cong Q.
\end{aligned}
\]
Both sides select exactly IDs 928 through 937.  For each selected group the
script additionally checks that the central kernel lies in the derived
subgroup, that
\[
  P_2(G)=G'=\Phi(G),
  \qquad G/\gamma_3(G)\cong\operatorname{SmallGroup}(32,27),
\]
and that the derived subgroup has one of the two claimed types.

It also identifies the unique class-two maximal subgroup \(B\), verifies
\[
\begin{gathered}
Z(B)=B'=\Phi(B)\cong C_2^2,\quad B/Z(B)\cong C_2^4,\quad
B/Z(G)\cong\operatorname{SmallGroup}(32,49),\\
Z(G)=G''=\gamma_4(G),\qquad [B,t]=G'
\end{gathered}
\]
for an outside involution \(t\), and checks that the eight outside
involutions form one conjugacy class.  Their centralizer in \(B\) is \(D_8\)
for the six D-types and \(Q_8\) for the four Q-types.  Only the two endpoint
bases decompose, as \(D_8\times D_8\) and \(Q_8\times Q_8\).  A direct
conjugacy-class test finds that \(B\) is Camina exactly for IDs 931 through
935.

The script constructs 16 finite presentations: two fixed central-lift
patterns and every binary triple \((a,b,c)\).  All have order 128 and the
target property.  Their isomorphism IDs are

```text
D: [928,931,929,932,929,932,930,933]
Q: [934,936,935,936,935,936,935,937]
```

in lexicographic parameter order.  Thus the two patterns collapse to exactly
six and four isomorphism types and exhaust the ten groups.  A scan of all five
order-eight seed wreath products separately proves that only IDs 928 and 937
are ordinary \(A\wr C_2\).

`validate_order128_parameter_orbits.g` goes beyond comparing catalogue IDs.
For every one of the 16 presentations, it exhausts the six ordered bases of
\(\mathbb F_2^2\), all involutory lifts of the top generator, and all
derived-subgroup corrections.  It accepts a transformed tuple only after
checking the entire normalized presentation and generation of the group.  It
proves the orbit rules
\[
\begin{array}{ll}
D\text{-pattern}:&c\text{ fixed and }S_2\text{ swaps }(a,b),\\
Q\text{-pattern}:&c\text{ fixed and }\operatorname{GL}(2,2)
  \text{ acts on }(a+c,b+c).
\end{array}
\]

Finally, the script scans every 2-group below order 128.  The only
exponent-eight groups with nonabelian Frattini subgroup are
\([64,32]\), \([64,33]\), \([64,36]\), and \([64,37]\).  Each has 12 square
values generating its 16-element Frattini subgroup, so the values are not
closed.  Every order-128 hit contains two or three such maximal subgroups.
At the same time its own square and fourth-power value sets are subgroups.
This mechanically verifies that all ten are weakly power closed in
themselves but not section-wise power closed.
